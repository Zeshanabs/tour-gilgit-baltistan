# GB Tourism Backend

Express API for the Gilgit-Baltistan tourism website.

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a `.env` file from `.env.example` and set your MongoDB URI.
3. Start the server in development mode:
   ```bash
   npm run dev
   ```

The server listens on `PORT` from your `.env` file (default `5000`).
